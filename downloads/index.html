Stremio addons

Sign in to Stremio first. "Install" opens Stremio's install screen; "Set up" opens the addon's own page to choose options, then install from there. Addons sync to every device on the same Stremio account.

  • My Trakt Lists Your Trakt lists as rows in Stremio, with optional Add to list buttons. Opens the setup page: choose your lists, then press Install. Needs your Trakt account for add buttons Set up
  • My Trakt Lists – Kids (7+) Ready-made kids setup: Disney, Pixar, DreamWorks, Nickelodeon, kids shows and more, filtered to PG / TV-PG. No add buttons. One-click install Install
  • Torrentio Finds the links to play movies and shows. Pick your options and add your Real-Debrid key on its setup page. Needs your own Real-Debrid key Set up
  • Streaming Catalogs Rows for Netflix, Disney+, Prime Video, HBO Max, Apple TV+, Hulu, Crunchyroll and more. Choose your services, then install. Setup page Set up
  • MyAnimeList – Top of All Time The highest-rated anime of all time. Official Stremio catalog · one-click install Install
  • Best Anime Top-rated anime movies and series. Official Stremio catalog · one-click install Install
  • Popular Anime What's popular in anime right now. Official Stremio catalog · one-click install Install
  • New Anime Recently released anime. Official Stremio catalog · one-click install Install
  • Popular Anime (Eng Dub) Popular anime with English dubs. Official Stremio catalog · one-click install Install
  • Top 100 Anime (Eng Dub) The top 100 English-dubbed anime. Official Stremio catalog · one-click install Install
  • Christmas Movies Popular Christmas movies, for the holidays. Official Stremio catalog · one-click install Install
